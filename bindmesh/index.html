Bake Layer Data to Blender Native¶

Click Current Bind Mesh to open a dropdown list showing all bind meshes in the scene.

  • The model has been initialized layers with Super Skin Pro.
  • The model has been initialized layers with Super Skin Pro but is missing the Armature Modifier.
  • The model uses native Blender data.

You can Click Bake Selected / Bake All : Bake all layer results back to native Blender.

Baking Merges Layers

Once baked, all layers will be merged. If you want to keep them, you can Export Weight first or don't bake. You can still share the unbaked file with anyone, even if they don't have this add-on.

Editing Without Baking

If you continue skinning using native Blender without baking, returning to the add-on tools will overwrite your changes with the last saved add-on state.
