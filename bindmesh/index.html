Bake Layer Data to Blender Native¶

Click Current Bind Mesh to open a dropdown list showing all bind meshes in the scene.

  • The model's layers have been initialized with Super Skin Pro.
  • The model's layers have been initialized with Super Skin Pro, but it is missing the Armature modifier.
  • The model uses native Blender data.

Click Bake Selected or Bake All to bake the layer results back to native Blender weights.

Baking Merges Layers

Once baked, all layers will be merged. To keep them, export the weights first, or don't bake. You can still share the unbaked file with anyone, even if they don't have this add-on.

Editing Without Baking

If you continue skinning using native Blender without baking, returning to the add-on tools will overwrite your changes with the last saved add-on state.
