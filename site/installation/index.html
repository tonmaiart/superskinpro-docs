Drag and Drop Installation¶

  1. Download the Super Skin Pro .zip file from Gumroad
  2. Open Blender, then drag and drop the .zip file onto the Blender window and confirm the install.
  3. Once installed, SuperSkinPro will appear in the N-Panel sidebar. Enter your Activate Key from Gumroad and press Activate to finish.

Manual Installation¶

If drag-and-drop installation doesn't work, you can install manually instead.

  1. Download the Super Skin Pro .zip file from Gumroad
  2. Go to Edit > Preferences > Add-ons
  3. Click Install... (top-right corner)
  4. Select the downloaded .zip file, then click Install Add-on
  5. Once installed, SuperSkinPro will appear in the N-Panel sidebar. Enter your Activate Key from Gumroad and press Activate to finish.

System Requirements¶

Each add-on version is generally designed to be compatible with Blender 4.2 LTS and newer, supporting Windows, macOS, and Linux. To be sure, you can check each version's requirements on the Release Notes page.

Automatic Add-on Updates¶

  1. When a new version is available, the add-on will normally notify you and let you update automatically.
  2. Restart Blender after the add-on finishes installing.
