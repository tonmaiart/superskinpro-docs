Drag-and-Drop Installation¶

  1. Download the SuperSkinPro .zip file from Gumroad.
  2. Open Blender, drag and drop the .zip file directly into the Blender viewport/window, and confirm the installation.
  3. Restart Blender after installing or updating the add-on.
  4. Once installed, SuperSkinPro will appear in the N-Panel sidebar.

Always Restart Blender After Updating or Reinstalling

If you update or reinstall the add-on, you must always restart Blender afterward to ensure the add-on works properly.

How to Update¶

When a new update is released, you can re-download the latest SuperSkinPro files from your Gumroad Library and repeat the installation steps above.
