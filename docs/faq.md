# FAQ

## 1. Which Blender versions does the Add-on support?

Support Blender 4.2 / 4.5 / 5.0 / 5.2 

## 2. Can I set my own shortcuts?

Yes. Go to the add-on panel, then click `Settings > Edit Shortcuts`
